# Rhetoric and persuasion

Classical rhetoric divides a speech into invention, arrangement, style, memory
and delivery. A debater still uses all five. Invention finds the argument.
Arrangement decides which point opens and which point closes. Style chooses the
words. Memory and delivery decide whether the audience believes the speaker. The
strongest argument delivered fourth in a list of four is often lost, which is why
speakers put their best material where attention is highest.
